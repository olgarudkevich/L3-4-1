* **Опис роботи:**
У цій практичній роботі я розробила Windows Forms застосунок на C++ для створення та налаштування 2D-графіки за допомогою класів Graphics, Pen та Brush. Інтерфейс програми складається з полотна для малювання, компонента ListBox для вибору потрібної фігури (від простих ліній до складеного "будиночка") та ComboBox для вибору кольору. У коді я реалізувала логіку, яка спочатку очищає екран, а потім через оператор switch динамічно відмальовує обраний примітив заданим кольором, миттєво оновлюючи малюнок при змінах у меню.
